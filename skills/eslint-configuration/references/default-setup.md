# House style (ESLint)

Use this for new setups. In an existing repo, match what is there. This file has the shared core and the plain TypeScript/Node and Next.js variants.

## What all five repos share

- ESLint 9 flat config in `eslint.config.mjs`. None of the five is on ESLint 10 yet.
- `eslint-plugin-prettier/recommended`, with `eslint-plugin-prettier`, `eslint-config-prettier` and `prettier` installed. It enables `prettier/prettier`, turns on eslint-config-prettier and turns off `arrow-body-style` and `prefer-arrow-callback` (eslint-plugin-prettier README).
- `eslint-plugin-simple-import-sort` with both `simple-import-sort/imports` and `simple-import-sort/exports` set to `"error"`.
- Prettier (`.prettierrc` with `{ "singleQuote": true }` and `.prettierignore`), Husky 9, lint-staged and commitlint on every commit.

## Where the repos differ

| Topic                          | What the repos do                                                                                                                                                   | Default for a new setup                 |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------- |
| Unused code                    | `eslint-plugin-unused-imports` with `^_` ignore patterns (desvia, quotahit); `@typescript-eslint/no-unused-vars` with `^_` (relay, cite); framework default (sonar) | unused-imports (newest repos)           |
| Type-only imports              | `@typescript-eslint/consistent-type-imports` with `prefer: 'type-imports', fixStyle: 'inline-type-imports'` (relay, cite); not set (desvia, quotahit, sonar)        | Enable it, as relay and cite do         |
| Wrapper                        | `defineConfig` and `globalIgnores` from `eslint/config` (quotahit, relay, cite, sonar); plain array as generated by Nx (desvia)                                     | `defineConfig`, except in Nx workspaces |
| Extra typescript-eslint config | `...tseslint.configs.recommended` on top of the Next.js configs (quotahit)                                                                                          | Include it                              |
| Agent directories              | `.claude/**` and `.agents/**` globally ignored (quotahit)                                                                                                           | Ignore them when they exist             |
| Quote style, `printWidth`      | Prettier settings (prettier-configuration house style)                                                                                                              | Single quotes, default `printWidth`     |

If the target repo already made one of these choices, keep it. Otherwise use the default column and tell the user that it follows the newest repos (desvia, quotahit).

## Order inside the config

1. Shared configs: framework (`eslint-config-next`, `@nx/eslint-plugin`), `@eslint/js`, typescript-eslint.
2. `eslint-plugin-prettier/recommended`. Its README asks for it to be last so eslint-config-prettier can turn off conflicting rules from earlier configs.
3. The house rules object. It holds no formatting rules, so placing it after the Prettier config is safe.
4. Global ignores.

## Plain TypeScript / Node

Sources: no repo is a plain Node service. This variant combines the shared core, quotahit's `typescript-eslint` usage and unused-imports block, relay and cite's type-import rule, and `@eslint/js` plus `globals` as shown in the ESLint docs.

```js
// eslint.config.mjs
import js from '@eslint/js';
import { defineConfig, globalIgnores } from 'eslint/config';
import prettierRecommended from 'eslint-plugin-prettier/recommended';
import simpleImportSort from 'eslint-plugin-simple-import-sort';
import unusedImports from 'eslint-plugin-unused-imports';
import globals from 'globals';
import tseslint from 'typescript-eslint';

export default defineConfig([
  {
    files: ['**/*.{js,mjs,cjs,ts,mts,cts}'],
    plugins: { js },
    extends: ['js/recommended'],
    languageOptions: { globals: globals.node },
  },
  ...tseslint.configs.recommended,
  prettierRecommended,
  {
    plugins: {
      'simple-import-sort': simpleImportSort,
      'unused-imports': unusedImports,
    },
    rules: {
      'simple-import-sort/imports': 'error',
      'simple-import-sort/exports': 'error',
      '@typescript-eslint/consistent-type-imports': [
        'error',
        { prefer: 'type-imports', fixStyle: 'inline-type-imports' },
      ],
      'no-unused-vars': 'off',
      '@typescript-eslint/no-unused-vars': 'off',
      'unused-imports/no-unused-imports': 'error',
      'unused-imports/no-unused-vars': [
        'warn',
        {
          vars: 'all',
          varsIgnorePattern: '^_',
          args: 'after-used',
          argsIgnorePattern: '^_',
          caughtErrorsIgnorePattern: '^_',
        },
      ],
    },
  },
  globalIgnores(['dist/**', 'coverage/**']),
]);
```

Dev dependencies: `eslint`, `@eslint/js`, `typescript-eslint`, `globals`, `eslint-plugin-prettier`, `eslint-config-prettier`, `prettier`, `eslint-plugin-simple-import-sort`, `eslint-plugin-unused-imports`.

## Next.js app

Sources: quotahit (structure, typescript-eslint, unused-imports, ignores); relay and cite (type-import rule). sonar has only the shared core; relay and cite use the alternative unused-variable rule shown after the config.

```js
// eslint.config.mjs
import { defineConfig, globalIgnores } from 'eslint/config';
import nextVitals from 'eslint-config-next/core-web-vitals';
import nextTs from 'eslint-config-next/typescript';
import prettierRecommended from 'eslint-plugin-prettier/recommended';
import simpleImportSort from 'eslint-plugin-simple-import-sort';
import unusedImports from 'eslint-plugin-unused-imports';
import tseslint from 'typescript-eslint';

const eslintConfig = defineConfig([
  ...nextVitals,
  ...nextTs,
  ...tseslint.configs.recommended,
  prettierRecommended,
  {
    plugins: {
      'simple-import-sort': simpleImportSort,
      'unused-imports': unusedImports,
    },
    rules: {
      'simple-import-sort/imports': 'error',
      'simple-import-sort/exports': 'error',
      '@typescript-eslint/consistent-type-imports': [
        'error',
        { prefer: 'type-imports', fixStyle: 'inline-type-imports' },
      ],
      'no-unused-vars': 'off',
      '@typescript-eslint/no-unused-vars': 'off',
      'unused-imports/no-unused-imports': 'error',
      'unused-imports/no-unused-vars': [
        'warn',
        {
          vars: 'all',
          varsIgnorePattern: '^_',
          args: 'after-used',
          argsIgnorePattern: '^_',
          caughtErrorsIgnorePattern: '^_',
        },
      ],
    },
  },
  globalIgnores([
    '.next/**',
    'out/**',
    'build/**',
    'coverage/**',
    '.yarn/**',
    '.claude/**',
    '.agents/**',
    'next-env.d.ts',
  ]),
]);

export default eslintConfig;
```

- Add generated output to the ignores (quotahit: `src/generated/**` for the Prisma client). relay and cite also ignore `.vercel/**`, `dist/**`, `playwright-report/**` and `test-results/**`; cite ignores `public/**`.
- relay and cite replace the unused-imports block with:

```js
'@typescript-eslint/no-unused-vars': [
  'error',
  { argsIgnorePattern: '^_', varsIgnorePattern: '^_' },
],
```

Dev dependencies: `eslint`, `eslint-config-next` (same version as `next`), `typescript-eslint`, `eslint-plugin-prettier`, `eslint-config-prettier`, `prettier`, `eslint-plugin-simple-import-sort`, `eslint-plugin-unused-imports`.

## Scripts, hooks and CI

- `"lint": "eslint ."`, `"lint:fix": "eslint . --fix"`, `"format": "prettier --write ."`, `"format:check": "prettier --check ."`, and `"postinstall": "husky"` on Yarn (`"prepare": "husky"` on npm, pnpm or bun).
- `.prettierrc`: `{ "singleQuote": true }`, plus `.prettierignore` (`dist`, `coverage`, `.yarn`, `node_modules`).
- `lint-staged` in `package.json`:
  ```json
  {
    "lint-staged": {
      "*.{ts,tsx,js,jsx,cjs,mjs}": ["eslint --fix", "prettier --write"],
      "*.{json,md,css,yml,yaml}": ["prettier --write"]
    }
  }
  ```
- `.husky/pre-commit`: `yarn lint-staged` (or `npx lint-staged` / `pnpm exec lint-staged`). Dev dependencies for hooks: `husky`, `lint-staged`.
- CI (quotahit, relay): `corepack enable`, `yarn install --immutable`, then `yarn lint`, typecheck, tests and build.
- All five use Yarn 4 with `nodeLinker: node-modules`.
